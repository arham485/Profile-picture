# GitHub Pages

Put the project files in the root of your repository:

```text
index.html
app.js
styles.css
firebase-config.js
firestore.rules
README.md
GITHUB_PAGES.md
photos/
```

Open repository Settings, choose Pages, select Deploy from a branch, choose `main` and `/ (root)`, then save.

After deployment, copy your live GitHub Pages domain into Firebase Authentication authorized domains.
